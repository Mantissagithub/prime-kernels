# Experiment 233: exact B1 integer addition improves generation

The accepted opt-in lossless decoder uses __vadd2 for B1 packed exponent addition. This is per-halfword integer arithmetic, with unchanged BF16 storage and floating-point operations. Base <=255 and delta <=7, so each halfword sum <=262 and cannot carry across fields. The CPU proof exhausts all 16,384 base/delta-pair combinations. GPU all-bit-pattern/mixed-delta proof passes four passes of 4,915,200 words, covers all 65,536 BF16 patterns, 64 delta pairs at four positions over 248 bases, and verifies refresh/descriptor stability. NVIDIA intrinsic definition: https://docs.nvidia.com/cuda/archive/13.1.1/cuda-math-api/cuda_math_api/group__CUDA__MATH__INTRINSIC__SIMD.html

Five matched uninstrumented decoder processes, three alternating blocks each and 120 events per arm/case, compare to the previous actual B1+B2 package. B1 median paired latency change at contexts 32/128/1024 is -0.916%, -0.704%, -0.795%; strict blocks 11/15, 15/15, 15/15. Short-context misses are retained. Exact hidden/KV bits and captured poisoned fallback/GU-only refresh pass at both batches. B2 stays byte-identical: no B2 gain claim.

Five fresh serial alternating vLLM processes per arm, five timed repeats per shape, use fixed token-ID prompts and 64 greedy tokens with ignore-EOS, equal KV capacity, graphs [1,2], and the same model/wrapper/cache. Generation excludes startup and RL training. B1 control/candidate median ms: context32 218.842/216.914 (-0.881%); 128 221.376/219.627 (-0.790%); 1024 262.156/260.198 (-0.747%). All five candidate process medians are below all five controls at each B1 context. Tokens, work and sampled-token logprobs are exact; B2 ranges overlap.

The final package uses a single templated helper to avoid duplication. Its B1/B2 instruction words, including scheduling control bits, exactly match the private measured variant. B1 grows 8,616 to 8,720 instructions; it does not get faster by reducing instruction count. Registers/shared/spills remain 253/38,440/0 for B1 and 246/44,848/0 for B2. A final packaged comparison passes exact six-case outputs and graph refresh; B1 medians -0.849/-0.784/-0.843%, strict 2/3,3/3,3/3. All 34 micro/serving/integrated guard records pass with zero job swap.

The integrated full-parameter RL run passes two updates and three lossless-cache refreshes to generation four, all 32 layers enabled. Loss/gradient/KL are finite. It sampled 220 rollouts /110 tasks /24,184 tokens; wrapper interval 62.925581 s, peak GPU 7,220 MiB, zero cgroup swap. FP32 optimization/reduction, rewards and admission unchanged. This is functional validation with different rollout work from earlier runs, NOT a verified RL wall-time gain. The main verified RL curve stays unchanged.
