# Experiment 219 research evidence

Measured directory is `outputs/megakernel-20261025/gateup-lossless-predicated-decode-r1` in tiny-prl. Predicated PTX plane/raw loads and word selection replace the decoder branch while keeping packed arithmetic, per-row hints, projection math and row mapping unchanged. Four selections consume all inputs into scoped PTX temporaries before output operands are written. An earlier source draft lacked that lifetime guarantee; it was corrected and independently re-reviewed before building.

This is a compressed-decoder component improvement, not serving or RL adoption. First valid run measures SIMD 75.424 to predicated 56.768 us per layer. A balanced three-arm repeat measures dense 48.650000, SIMD 79.803497, predicated 61.214501 us per layer. The repeat is 23.2935% lower than SIMD and 25.8263% higher than dense. Event ranges drift broadly across placements, so retain the raw samples and do not treat one percentage as a stable universal speedup. All three arm ranges are disjoint in the repeat. Six placements with five replays of 32 layers yield 960 timed layer calls per arm.

All 157,286,400 decoded candidate BF16 words match original weights exactly. All 327,680 outputs per arm match FP32 and BF16, and NaN-poisoned replay writes pass for all three graphs. Candidate uses 62 registers versus SIMD 80 and dense 64; all have 7,680 bytes shared memory, no spills and no stack. Valid run guards pass at 1,019 MiB GPU peak and zero swap.

Repeat attempt r2 failed before the benchmark because root omitted the inner guard-directory argument; it recorded zero GPU memory and no performance result. Its outer guard and launch log are preserved. Root then used the newly validated `run_micro.sh` operator wrapper for successful r3. The wrapper supplies both guard paths and refuses existing guard directories; its copied source is an audit artifact from `outputs/megakernel-20261025/runtime/`, where sibling `run_gpu.sh` exists. It is not a standalone archive-root launcher. The pinned venv was not changed.

Reports and SASS are deterministic gzip with hashes in `raw-output-manifest.json`. No weights or compiled libraries are included. Scripts retain original measured paths and require the bounded pinned-offline-uv operator workflow. Per-row first/count metadata packing is a future isolated trial, not a measured result here.
